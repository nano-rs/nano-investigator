This qualifies connectivity/auth boundaries only. Positive ingestion state/release responses remain fixture-verified because that key lacks `log_sources:view`, `parser_repositories:view` and `enrichments:view`. No broader key was used, and no tenant writes occurred.

## Migration

Investigator provides 18 diagnostic reads and six pipeline lifecycle WRITE tools aligned with nanodac (NAN-4013/4014); configure one ingestion tool provider per client when names overlap. Replace legacy `id` read arguments with `source_id`. Use `browse_parser_repository` for catalog pages and `get_pipeline_releases` for shared rollout history. This intentionally removes obsolete investigator MCP log-source shortcuts, transport deployment and retired 410 credential import registrations rather than adding compatibility shims. Existing non-ingestion tools and the core SDK's dedicated methods are outside this change.
